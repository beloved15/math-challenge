# math-challenge

Math Quiz Challenge

A fun and interactive mathematics quiz game built with Python and Streamlit. The application challenges players with randomly generated math questions, tracks their performance, and provides instant feedback to make learning mathematics more engaging.

Features
🎯 Interactive mathematics quiz
🧮 Multiple math operations and question types
🎲 Randomly generated questions for replayability
⏱️ Optional time-based challenge
📊 Real-time score tracking
✅ Instant answer feedback
📈 Performance summary at the end of each quiz
🎨 Clean and responsive Streamlit interface
🔄 Restart and play again functionality
Tech Stack
Python — Core programming language
Streamlit — Web application and user interface
Random — Question and number generation
Math — Mathematical calculations and operations
